# Demonstration outline

A useful walkthrough begins with a project goal and its task dependencies, then opens a selected task in Brief, Tool and Review. Explain what the model received, which checks ran, and what decision remains with the person.

The recorded release-packet checker demonstrates supplied-text validation. An incomplete example has three gaps; a corrected example has zero gaps and is ready for human review. Neither output approves a real release.

When a CSV export requirement is added, earlier checks remain evidence for the earlier request, not proof that CSV export was built. Show the preserved tool, the request change and the separate completion decision.

Label a recorded run as historical. Do not present the bundled recovery example or assistant-authored changes as a fresh successful model or Sandbox run. Verify the final recording, source, access and any links separately.
