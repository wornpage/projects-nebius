# Source provenance

The underlying Wornpage Projects concept and public component packages predate this Nebius edition. The earlier WebMCP challenge edition supplied browser-local workspace and human-approval patterns; its public baseline remains separate.

This edition adds Nebius Token Factory integration, bounded task-to-tool execution, Sandbox checks and repair, isolated preview, and task-scoped evidence review. It is not a claim that the earlier Projects concept or components were created for this challenge. The private Projects backend is not a dependency of this edition.

The frontend lockfile records pinned source revisions and integrity values for the public Wornpage component packages. See LICENSE, LICENSING.md and the third-party notices for applicable attribution and terms. Review the exact source revision and its history before distribution.
