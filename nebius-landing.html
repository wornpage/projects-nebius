One task. A complete build loop.

The next step can be something you can use.

Start with a saved task and clear completion criteria. Open Task → Tool, review the input and limits, then let the agent work through the run.

1

Define the task

Give the agent a purpose, a next step and a clear description of done. Preview exactly what you send.

2

Generate the tool

Nemotron writes a small browser tool from the task you chose, together with checks for its behavior.

3

Run and repair

Token Factory Sandboxes execute the checks. If a check fails, the agent may try one repair. If that repair passes validation, the checks can run again.

4

Review the result

Open the preview, read the code and check output, and save useful evidence back to the task.

About this edition

Built on our earlier browser-local workspace and approval controls. The Nebius edition adds project planning, task guidance, evidence review, replanning and a Sandbox execution workflow. Your project stays in this browser; authorized runs also retain their selected task and results on the server for seven days. Download a workspace backup from the Work menu to keep saved work.
