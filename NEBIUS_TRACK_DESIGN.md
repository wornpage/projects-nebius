# Track fit and model routing

The Nebius edition is a project workflow with an optional coding-agent path: a person authorizes a task-scoped build, a selected NVIDIA model proposes browser-tool source, and Nebius Sandbox can run the generated checks. The person reviews the source, evidence and completion decision.

The operator selects available NVIDIA model IDs and configures each role explicitly. No model or alternate provider is silently selected. The application exposes configured request and resource limits; those limits are not a guaranteed dollar budget.

Manual work and bundled examples do not require a provider call. Actual model quality, availability, costs and judge access must be established separately for the selected deployment. See NEBIUS.md and NEBIUS_EXECUTION.md for setup and runtime boundaries.
