# Evidence and review

Review the exact source and environment being considered. Historical runs, saved examples and previous test reports apply to the sources and conditions they actually measured; they do not automatically qualify a later candidate.

Inspect Work and Task, task editing, generated source, request changes, evidence saving and the separate completion decision. Check keyboard navigation, focus, narrow layouts and accessibility using appropriate tools and human review.

A local preview or synthetic test is not a hosted deployment, live model result or judge-access proof. Keep failures and uncertain outcomes visible, and do not infer a new provider call from a replay.
