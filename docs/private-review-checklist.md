# Review checklist

Use the credential-free setup in README.md and review the exact candidate. No provider key is required for manual workflows and bundled examples.

1. Run the applicable source, frontend and browser checks. Record the source revision, environment, failures and each distinct test population.
2. Inspect Work → Task and the Brief, Tool and Review views. Check keyboard focus, labels, narrow layouts and evidence-saving behavior.
3. Confirm a changed request cannot use an earlier run as proof of the new requirement. Saving evidence and marking work done are separate decisions.
4. Distinguish model-authored checks, application structural checks and independent observations. A replay is not a fresh provider call.
5. Review source and dependency licensing, private material, deployment configuration and judge access separately before a release.

Automated checks do not by themselves establish full accessibility conformance, model quality, hosted behavior or human acceptance.
