# Recovery example provenance

The bundled Recovery Simulator is a fixed five-task modeling example. Its current source includes assistant-authored repairs and extensions after an earlier model attempt failed. This example is not an untouched successful model or Sandbox result.

Its inputs and projected outputs are described in recovery-simulator.md. The example is available without a provider call. Earlier source and provider records apply to their own revisions and are not implied by opening the bundled example.

For a fresh build, preserve the actual request, model result, Sandbox outcome and independently observed behavior separately. Do not infer a successful generation from a local repair or authored fixture.
